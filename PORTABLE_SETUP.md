# Переносимый запуск

Актуальная инструкция установки и описание проекта: [INSTALL_RU.md](INSTALL_RU.md).

Для тестового запуска Meta и Telegram не обязательны. Пароль MYSQL_ROOT_PASSWORD должен отличаться от MYSQL_PASSWORD; в DATABASE_URL используется только пароль пользователя MYSQL_USER.

Локальные `.env`, токены, базы и резервные копии в репозиторий не входят.
