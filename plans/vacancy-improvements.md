# Улучшение вакансий

1. Общий вычисляемый паспорт вакансии: структурированные ставки (сумма, валюта, basis,
   студент, UDT, исходный фрагмент), состояния полей и готовность.
2. История ручных изменений и preview перепарсинга сохранённого источника; применение
   выбранных полей отдельно, без перезаписи всей записи.
3. Дубли: сравнение исходного текста и фактов, предупреждение; деактивация только вручную.
4. UI: обе ставки, единая валюта, готовность, источники, история и массовый preview.
5. Генерация: preview фактов и разбиение длинного текста на связанные черновики.
6. Устаревание: отдельная дата подтверждения источника, предупреждение через 14 дней.
7. Supervisor: read-only качество вакансий; без автоматического изменения фактов.
8. API/backend/UI проверки, сборка и применение Docker.

Неизвестные условия сохраняются как MISSING. Числовую вероятность корректности
не придумываем: CONFIRMED означает явное значение источника; конфликт требует проверки.
Новые API вычисляют паспорт из существующих полей, поэтому изменение схемы БД не требуется.
