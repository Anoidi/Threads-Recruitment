# Редакторская память

Сохраняем причину человеческой правки вместе с версиями до/после в ActivityEvent.
Категории стиля имеют фиксированные формулировки; фактические исправления не создают предпочтений.
Предложения группируются по языку, типу публикации и категории, учитывают разные посты.
Оператор может подтвердить предложение после одного примера; после двух оно отмечается как повторяющееся.
Решения сохраняются в AppSetting. В генерацию попадают только подтверждённые правила соответствующего scope.
Планировщик получает подтверждённые правила через editorial_evidence.
Отключение немедленно исключает правило из следующей генерации. Публикация проходит прежний publish-gate.
Проверки: сохранение diff/версий, фактические правки, подтверждение/отключение, scope, prompt injection,
API и использование правил генератором. Затем сборка и обновление Docker.
