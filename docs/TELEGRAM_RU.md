# Telegram: импорт вакансий из канала

[К полной настройке](SETUP_RU.md)

## Что именно подключается

Приложение использует Telegram Bot API: бот получает **новые** записи и изменения записей канала, worker извлекает вакансии и создаёт черновики Threads. Вход в личный Telegram по номеру телефона, SMS, QR или session-файлу не реализован. Отправка сообщений от вашего личного аккаунта и выгрузка полной истории канала также не реализованы.

Текущий фильтр в `worker/sources.py` сравнивает `chat.username` с `TELEGRAM_CHANNEL`. Поэтому используйте канал с публичным username. Приватный `-100...` ID, ссылка-приглашение и произвольный чужой канал этим импортёром не поддерживаются. `telegram_contact` в настройках контента не является подключением бота.

## 1. Создать бота

1. В Telegram откройте официального [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, укажите название и свободный username, заканчивающийся на `bot`.
3. Сохраните выданный токен **локально**. Не присылайте его агенту в чат и не публикуйте скриншот ответа BotFather.
4. Добавьте этого бота администратором своего канала. Для импорта не нужно давать право удалять сообщения или добавлять администраторов. Нужен канал, которым вы можете управлять.

Используйте отдельного бота для этого проекта: два клиента `getUpdates` с одним токеном мешают друг другу. Если токен раскрыт, перевыпустите его через BotFather и обновите `.env`.

## 2. Настроить проект

```dotenv
TELEGRAM_BOT_TOKEN=YOUR_PRIVATE_BOT_TOKEN
TELEGRAM_CHANNEL=@your_public_channel
TELEGRAM_POLL_INTERVAL_SECONDS=60
```

Это поля `.env`, отдельной формы входа в Telegram в UI нет. Уберите пример канала автора из шаблона. Примените изменения:

```powershell
docker compose up -d --force-recreate backend worker worker-agents
```

Планировщик ставит `sync_telegram_vacancies` в очередь при наличии токена и канала. Интервал ограничивается кодом диапазоном 30–3600 секунд. Поллинг может обращаться к Telegram даже при `THREADS_MOCK_MODE=true` и `AI_MOCK_MODE=true`: эти флаги не являются mock-переключателем Telegram.

## 3. Проверить токен и webhook без показа секрета

Выполните в контейнере backend. Скрипт берёт токен из окружения, печатает только результат и username бота. Не запускайте терминал с записью сетевых URL: Bot API включает токен в путь запроса.

```powershell
@'
import json, os, urllib.request
token = os.environ.get('TELEGRAM_BOT_TOKEN', '')
if not token:
    raise SystemExit('TELEGRAM_BOT_TOKEN is empty')
for method in ('getMe', 'getWebhookInfo'):
    try:
        with urllib.request.urlopen('https://api.telegram.org/bot' + token + '/' + method, timeout=15) as response:
            data = json.load(response)
        result = data.get('result') or {}
        print(method, 'ok=', data.get('ok'), 'bot=', result.get('username'), 'webhook_active=', bool(result.get('url')))
    except Exception as exc:
        print(method, 'failed:', type(exc).__name__)
'@ | docker compose exec -T backend python -
```

Если `webhook_active=True`, `getUpdates` работать не будет. Для выделенного бота отключите webhook через `deleteWebhook` в Bot API, **сохранив pending updates** (`drop_pending_updates=false`). Сначала убедитесь, что webhook не обслуживает другой ваш проект. Это изменение конфигурации бота, а не шаг, который агент должен выполнять без понимания его назначения. Не вызывайте вручную `getUpdates` параллельно worker.

## 4. Проверить импорт

1. После добавления бота опубликуйте в своём канале новую тестовую вакансию — только если вы согласны на её публичное размещение. Например: первая строка «Вакансія: працівник складу», затем город, ставка, график и контакт. Или дождитесь следующей настоящей вакансии.
2. Подождите 1–2 интервала и обработку очереди.
3. Откройте «Вакансии» и «Контент». Найдите запись с источником Telegram и ссылкой на исходное сообщение.
4. Сверьте извлечённые условия, исправьте недостающие поля и подтвердите источник. Импорт не доказывает актуальность вакансии и не разрешает публикацию автоматически.
5. Для диагностики: `docker compose logs --tail 100 worker worker-agents`. Перед отправкой логов кому-либо удалите секреты и данные кандидатов.

Фильтр принимает текст или caption с признаками работы: `ваканс`, `робот`, `praca`, `oferta pracy`, `zatrudni`, `работ`. Фото без подписи и обычная запись без этих слов могут быть пропущены. Старые записи не скачиваются: Bot API хранит входящие updates ограниченное время (до 24 часов), это не API архива канала. Для старых вакансий создайте записи вручную или согласуйте отдельный импорт.

| Симптом | Проверка |
| --- | --- |
| Токен неверный | `getMe`, токен от нужного бота без пробелов |
| 409 Conflict | Другой polling-клиент либо активный webhook |
| Канал не импортируется | Бот добавлен, username совпадает, канал публичный |
| Старые посты не появились | Это ожидаемо; отправьте новую запись или импортируйте вручную |
| Запись есть, вакансии нет | Есть текст/подпись и слова фильтра, worker обрабатывает очередь |

Источники: [создание бота](https://core.telegram.org/bots/features#botfather), [Bot API: getUpdates, webhooks, channel_post](https://core.telegram.org/bots/api), [FAQ](https://core.telegram.org/bots/faq).
